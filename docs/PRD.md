# Product Requirements Document (PRD)

# Project

**Project Name:** LMSCA

**Product Type:** Global Live Cohort Learning Platform

**Version:** 1.0 (MVP)

---

# Product Vision

LMSCA is a cloud-based learning platform designed to deliver instructor-led live cohort programs. The platform enables students to enroll in structured courses, attend live classes, complete assignments and assessments, track progress, and receive a seamless learning experience.

The platform also provides complete back-office automation for admissions, batch management, payments, notifications, and operational workflows.

---

# Objectives

- Deliver a premium learning platform
- Support live cohort-based education
- Automate admissions and operations
- Reduce manual administrative work
- Improve student engagement
- Support global learners
- Provide scalable architecture
- Deliver a modern user experience

# Core Business Workflows

## Admissions

Lead → Counsellor → Demo → Enrollment → Payment → Batch Assignment → Student

---

## Learning

Enrollment → Batch → Live Classes → Assignments → Assessments → Progress → Completion

---

## Teacher

Assigned Batch → Conduct Class → Review Assignments → Publish Assessment → Track Progress

---

## Administration

Manage Users → Manage Programs → Manage Batches → Monitor Reports → Configure Platform

---

# Business Principles

- Live cohort-based learning only
- Rule-based automation
- No AI-based decision making
- Configurable business rules
- Global learner support
- Responsive web application
- Secure role-based access
- Fully automated operational workflows

---

# Version 1 Exclusions

- AI Features
- Discussion Forum
- Gamification
- Referral System
- Affiliate System
- Recorded Video Library
- Mobile Application
- Multi-Tenant Platform
- Franchise Management
- Multi-Campus Management

---

# Success Criteria

The platform should enable organizations to:

- Manage admissions digitally
- Conduct live cohort-based learning
- Automate operational workflows
- Manage students and teachers
- Track learning progress
- Process payments
- Generate operational reports
- Operate with minimal manual intervention
